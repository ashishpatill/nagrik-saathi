# Two-minute demo script

1. Open Nagrik Saathi empty. Show `WebMCP ready` and the safety boundary.
2. Paste a real (or redacted personal) notice, click **Analyze**.
3. Switch the brief language EN / HI / MR.
4. Run next actions: Marathi explain → official portal → reminder deny/approve →
   family brief.
5. In the inspector, show all eight registered tools.
6. End on: “No payments or submissions are performed by this app.”

Never display credentials, OTPs, Aadhaar, PAN, or banking details in a recording.
