# Two-minute demo script

1. Open Nagrik Saathi empty. Show the safety boundary (no payments / submissions).
2. Paste a real (or redacted personal) notice, click **Analyze**.
3. Switch the brief language EN / HI / MR.
4. Run next steps: Marathi explain → portal → scam check → action plan →
   reminder deny/approve → family brief → citizen letter draft.
5. Optional for judges: open `/?inspector=1` to show WebMCP status and eight tools.
6. End on: “No payments or submissions are performed by this app.”

Never display credentials, OTPs, Aadhaar, PAN, or banking details in a recording.
